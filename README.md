# gamrisa-cbt
정보시스템감리사 기출문제 CBT 연습 프로그램(R의 shiny 패키지 이용)
- 스스로 pdf를 문항단위로 이미지를 잘라서 문제를 보여주고 정답여부를 알려줌
- NIA의 자료실에서 공개한 과거 pdf에서 정답표시만 제거하여 추출한 pdf를 입력으로 받음(2026년 기준 누적 약 1400여개 문제)
- 문제 풀이를 모르면 이미지를 복사해서 제미나이에게 설명해달라고 해서 메모에 추가하면서 학습 가능(메모에 수식이 들어가는 경우 수식보기도 지원)
- 5개 각 과목내에서도 영역(domain)을 5가지 정도로 나누어 세부 문제풀이 가능
- 엑셀 위장모드(몰래 공부할 수 있게 엑셀 작업중 학습하는 것처럼)

ㅁ 사용법 

1. 본 파일들을 모두 한 폴더에 넣어 놓고 Rstudio에서 app_light.R을 열고 'Run App' 버튼을 누른다.
2. 웹브라우저 창이 열리면 좌상단에서 연습할 연도의 감리사기출문제를 콤보박스에서 선택하고 'CBT 문제 불러오기'를 클릭 또는 전체 문제에서 특정 과목만 골라서 문제 풀이 가능
3. 문제를 풀면서 다음버튼을 누르면 되고, 문제 오른쪽에 문제별로 메모 및 저장도 가능함(난이도 저장, 연도별 불러오기/특정과목만 불러오기, 마지막 문제풀이 자동 저장 기능 등)
